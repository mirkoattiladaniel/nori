# std

The **Nori standard library**: the modules every Nori program can import by name, with
`import "std/NAME" as NAME`. Each module is a directory here.

The reference for every module (what it is for, how to import it, and its public API) is in
[docs/std](../docs/std/), and at [nori-lang.com](https://nori-lang.com/docs/std/).
